# Мои расчёты — приложение для iPhone (PWA)

Веб-приложение с разделами **«Расчёты»** и **«Финансы»**. Работает из Safari и может быть установлено на экран «Домой» как PWA.

## Запуск

После публикации GitHub Pages: **https://aberdyshev-ki15.github.io/raschety/**

На iPhone откройте ссылку в Safari, нажмите **«Поделиться» → «На экран Домой» → «Добавить»**. Для первого запуска и обновления требуется интернет; основные страницы и библиотеки кэшируются для автономной работы.

## Развёртывание

1. В настройках репозитория откройте **Settings → Pages**.
2. Выберите **Build and deployment → Source → GitHub Actions**.
3. В разделе **Actions** дождитесь успешного выполнения **Deploy PWA to GitHub Pages**.
4. Откройте адрес выше.

## Файлы

- `index.html` — интерфейс и логика приложения, локальное хранение данных и экспорт/импорт резервной копии.
- `manifest.webmanifest` — параметры установки на iPhone.
- `sw.js` — автономный кэш.
- `icons/` — значки.
- `vendor/` — локальные библиотеки экспорта.
- `template.txt` — шаблон для генерации документа.

## Конфиденциальность и резервное копирование

Данные вводятся и хранятся **локально на устройстве** (localStorage), не синхронизируются между устройствами и не сохраняются в GitHub. Это не банковская интеграция. Не удаляйте данные сайта в Safari без резервной копии. Для переноса на другой телефон экспортируйте резервную копию через кнопку ⚙ и импортируйте её на новом устройстве.

Репозиторий **публичный**: размещайте здесь только код и шаблоны без личных финансовых записей. Автономная доступность шрифтов и отдельных функций может зависеть от первого подключения к сети.
